# 4Muslims — AI Verse Studio & Free Quran Companion

4Muslims is a web app that combines two things Muslim creators and everyday users need: an AI-powered video studio for producing beautiful, vertical Quran verse videos, and a full-featured, always-free Quran companion.

## Features

### AI Verse Studio
- Pick a surah and ayah, choose from 5 renowned reciters, and select a cinematic vertical (9:16) template
- AI-generated verse videos ready to share
- Render library with history, status tracking, and downloads
- Auto-post to YouTube Shorts, TikTok, and Facebook (PRO/ULTIMATE plans)
- Social integrations and subscription billing

### Free Quran Companion (available to every user, on every plan)
- **Quran Reader** — read and listen to all 114 surahs and 30 juz, with Arabic text and English translation
- **Prayer Times** — accurate daily prayer times by location, with a live countdown to the next prayer
- **Duas & Dhikr** — browse and search daily supplications and after-salah dhikr by category
- **Favorites & History** — save favorite ayahs and keep track of recently read verses (stored on-device)

### Personalization
- Dark and light themes
- Interface available in English, Arabic, Hausa, and Yoruba

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide icons
- Supabase (`@supabase/supabase-js`)
